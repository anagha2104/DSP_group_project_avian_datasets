This dashboard explores the Avonet bird dataset where you can filter species by ecology and geography, then inspect one trait at a time with histograms, bar charts, and summary statistics alongside an interactive world map. It links any two features using scatter plots, regression, and short takeaways. It compares multiple species with radar charts, trait tables, geographic layout, and optional phylogenetic distance, and ranks the closest species to your measured traits using normalized distances.
